# Personal Portfolio

Hey, I'm **Jesse Kimsupasuk**, an Electrical and Electronics Engineering (Hons) student at the University of Canterbury. This is a personal repository of everything I have built to showcase my projects over the years! Later this year, I'll create a portfolio website to make it easier to navigate and find the projects that interest you the most.

This is a place where I go into more detail about the projects I've completed both inside and outside of my courses, so any questions about them are always appreciated. A summary of the projects included is shown below:

* **Australian Universities Rocketry Competition (Kōtare) 2026** - Photos and videos from the manufacturing process are compiled into one place. They mostly cover the build process, CAD modelling, composite manufacturing, and avionics.
* **Line-Following Robot** - Two versions of the robot are shown with schematics, PCB layouts, and CAD models used to create autonomous behaviour through hardware and software.
* **Passion Projects** - These consist of various projects that are currently underway. At the moment, I am developing an avionics flight computer alongside my studies, with plans to build a solar-powered drone later this year.
* **Portfolio Document** - A write-up of engineering problems I faced during recent projects, including AURC 2026, and how I solved them.
